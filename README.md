A modern, responsive portfolio website showcasing the work and skills of Eva Suarez, a passionate Full-Stack Developer specializing in MERN Stack, Laravel, and React Native development.

## 🌟 Features

### 🎨 Design & User Experience
- **Responsive Design**: Optimized for all devices and screen sizes
- **Dark/Light Theme Toggle**: Automatic theme detection with localStorage persistence
- **Smooth Animations**: CSS animations and JavaScript interactions for enhanced UX
- **Loading Screen**: Custom animated loading experience with dynamic tips
- **Back to Top**: Smooth scroll functionality for better navigation

### 📱 Portfolio Sections
- **Hero Section**: Professional introduction with contact information and social links
- **Projects Showcase**: Interactive project gallery with grid/list view toggle and filtering
  - E-Commerce Platform (MERN Stack)
  - Task Management App (React Native)
  - AI Chat Assistant (AI/ML)
  - Portfolio Website (HTML/CSS/JS)
  - Blog Platform (Laravel)
- **Skills & Expertise**: Categorized technical skills (Frontend, Backend, Mobile, Tools)
- **Work Experience**: Professional experience timeline
- **Awards & Certifications**: Recognitions and achievements

### ♿ Accessibility & Performance
- **SEO Optimized**: Structured data, meta tags, and search engine friendly
- **Accessibility**: Semantic HTML, ARIA labels, keyboard navigation, screen reader support
- **Performance**: Optimized assets, minimal JavaScript, responsive images
- **Cross-browser Support**: Compatible with modern browsers

## 🚀 Quick Start

1. **Clone or Download**: Get the portfolio files
2. **Customize Content**: Update personal information, projects, and contact details
3. **Add Assets**: Place your images in appropriate locations (see assets/README.md)
4. **Deploy**: Upload to your hosting platform

## 🎨 Customization Guide

### Personal Information
Edit the following sections in `index.html`:
- Hero section: Name, title, description, location
- Contact information: Email, social media links
- Skills section: Add or modify technical skills
- Experience section: Update work history
- Projects section: Replace with your actual projects

### Styling
- Colors are defined as CSS custom properties in `:root`
- Primary theme color: `--primary-color` (golden/orange)
- Responsive breakpoints follow Bootstrap standards
- Theme variables support both light and dark modes

### Assets
See `assets/README.md` for detailed information about required images and specifications.

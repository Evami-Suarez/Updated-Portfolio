# Assets Directory

This directory contains all the static assets for the portfolio website.

## Images (assets/img/)

The following images are referenced in the HTML and need to be added:

### Required Images:
- `logo.png` - Your logo (160x50px recommended)
- `favicon.png` - Favicon (32x32px or 16x16px)
- `profile.jpg` - Your profile picture (350x350px recommended, square format)
- `main.jpg` - Hero section background/main image (1200x630px recommended for OG tags)
- `project1.jpg` to `project5.jpg` - Project screenshots/thumbnails (400x220px)
- `company1.png` and `company2.png` - Company logos (90x90px)
- `cert1.jpg` - Certification image (200x200px)

### Optional Images:
- `DZB-LOGO.png` - Alternative logo if needed
- `DZB-FAVICON.png` - Alternative favicon
- `bok.jpg` - Alternative profile image

## How to Add Images:
1. Replace placeholder filenames with your actual images
2. Ensure images are optimized for web (compressed)
3. Use appropriate formats (JPG for photos, PNG for logos/graphics)
4. Update image paths in `index.html` if filenames change

## JavaScript (assets/js/)
- `script.js` - Custom JavaScript functionality

## Notes:
- All images should be optimized for web performance
- Consider using WebP format for better compression
- Add alt text for accessibility
